Property imagery
The property category galleries currently use illustrative stock photography from Unsplash via image URLs. Downloading those image binaries was blocked by network/DNS restrictions in the build environment. The assets/images folder includes instructions; replace the image URLs in properties.html and CSS with locally stored, licensed project images before publishing. No sample category is presented as a confirmed Empaadolisting.

Contact form
The demo form opens a prefilled email draft to hello@Empaado Company Ltdproperty.com. Confirm this is the correct company email and connect a backend/form provider for direct submissions.
